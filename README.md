# Ramlah's Personal Portfolio Website

## Project Overview

This project is a responsive personal portfolio website developed as part of my Web Technologies assignment. It introduces me, presents my educational background, skills, interests and projects, and provides an academic planner and contact form.

## Project Objectives

- To create a professional online portfolio.
- To demonstrate my knowledge of HTML, CSS and JavaScript.
- To build an interactive and mobile-friendly website.
- To showcase my learning journey and academic activities.

## Website Features

1. Home: Introduces me and includes my personal photograph and audio introduction.
2. About Me: Presents my educational background, career aspirations, technical skills and interests.
3. Projects: Displays sample projects with images and links.
4. Academic Planner: Allows users to add, complete, undo and delete tasks. Tasks are saved using local storage.
5. Contact: Provides a form with JavaScript validation for name, email, phone number and message.

## Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout and responsive design.
- JavaScript – Interactivity, form validation and task management.
- Browser Local Storage – Saving academic planner tasks.

## Project Structure

- "index.html" – Home page
- "about.html" – About Me page
- "projects.html" – Projects page
- "planner.html" – Academic Planner page
- "contact.html" – Contact page
- "style.css" – Website styling
- "planner.js" – Academic planner functionality
- "contact.js" – Contact form validation
- "images/" – Project screenshots
- "ramlah.jpg" – Profile photograph
- "introduction_mp3.aac" – Personal audio introduction
